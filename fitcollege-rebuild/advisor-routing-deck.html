HubSpot · form build spec

One form, every detail on one screen

Name: Website – Lead capture (advisor routing) 2026. One form for every enquiry: each submission triggers the info pack and creates the lead.

Visible fields

  • First name* · Last name* · Email*
  • Mobile* with country code dropdown (AU default)
  • course_interest* dropdown: labels exactly as course-routing.csv
  • where_do_you_live*: Australia / Outside Australia new
  • → if Australia: zip* (4 characters)
  • → if Outside: country* (conditional logic)
  • Consent naming phone, SMS and email

Hidden fields

  • lead_source_page: page they came from new
  • lead_context: e.g. checker-eligible new
  • assigned_advisor · lead_routing new: set by workflow (and by our code on legacy embeds)
  • UTMs, gclid, fbclid
  • Promotion form's hidden fields to copy

Form settings

  • CAPTCHA (reCAPTCHA): on
  • After submit: inline message, never a redirect (screen 2 replaces it)
  • Pre-populate known values: off for hidden fields
  • Region ap1; tell Kook the editor (new / legacy)
  • Send Kook the portal ID + form ID

HubSpot · automation & tracking

What happens after submit

Workflows

  1. Set contact owner, only if blank. Branches in rule order; values are paste-ready in data/hubspot-workflow-lists.txt. Also sets assigned_advisor + lead_routing. Kook: check HubSpot's limit on "is any of" values (Ryan has 1,057)
  2. SMS speed-to-lead names the advisor and repeats "within 1 business day". Skip it if they've already booked.
  3. Info pack to everyone: email the guide for course_interest (general guide for "Not sure yet").
  4. Task for the owner: due in 1 business day, so the promise is kept.

Tracking (GTM dataLayer → GA4)

  • lead_submitted conversion
  • advisor_book_opened: tapped "Book a time now"
  • advisor_meeting_booked conversion
  • advisor_call_clicked conversion
  • Each carries assigned_advisor + lead_routing: book vs call vs wait, per advisor

Edge cases & upkeep

No dead ends, no code edits

SituationBehaviour
Postcode not in sheetTeam promise + call option; lead_routing = unmatched for gap reports
OverseasCountry instead of postcode; international phone via country code
Advisor calendar empty (leave, full)"No times showing? Call 1300 887 017" under the calendar
Came straight to contact pageCourse defaults to "Not sure yet"; source page = contact
Returning lead, new postcodeOwner kept (owner-if-blank rule)
Spam botsHubSpot reCAPTCHA
JavaScript blockedPhone number shown instead

When territories or courses change

  1. Update POSTCODE MASTER and/or course-routing.csv.
  2. New advisor? Add a row to advisors.csv.
  3. Run python3 tools/build_advisor_routing.py "POSTCODE MASTER.xlsx". It stops on any clash.
  4. Deploy js/advisor-data.js and re-paste the changed branch in the HubSpot workflow from hubspot-workflow-lists.txt.
